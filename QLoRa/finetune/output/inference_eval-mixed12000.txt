Q: 写一个SQL查询：有一个订单表orders（字段：order_id, customer_name, amount, order_date），请找出2024年每个月的销售总额，并按月份升序排列。
============================================================
A: ```sql
SELECT 
    DATE_FORMAT(order_date, '%Y-%m') AS month,
    SUM(amount) AS total_sales
FROM orders
WHERE YEAR(order_date) = 2019 -- 假设数据在20XX-YY-MM格式中
GROUP BY month
ORDER BY month ASC;
```

注意：
1. `DATE_FORMAT` 和 `YEAR` 是 MySQL 函数名。
2. 确保日期格式为 YYYY-MM-DD 或类似格式。
3. 如果订单表中有客户信息但不需要分组显示，则可以省略 `customer_name` 列和对应的 GROUP BY 子句。
4. 如果只需要汇总而不关心具体哪些订单贡献了金额，则可以直接使用 `SUM()` 而不是 `SUM(customer_name)`。

Q: 如果你要创业开一家社区咖啡店，请给出一份简洁的商业计划，包含市场定位、选址要点和开业前三个月的营销策略。
============================================================
A: **社区咖啡厅商业计划**

### **1. 市场定位**
- 面向本地居民（30%），学生/上班族通勤者（45%），游客/商务旅客（25%）
- 定位：「在本地人中间的咖啡馆」——亲切、熟悉感，不是高端精品但也不像快消连锁

### **2. 选址要点**
- 中心城区步行街旁的小巷深处 —— 公交可达+隐藏感 = 潜客流量
- 租金低于市中心旗舰店的一半 -> 低成本启动 + 资本积累空间
- 地下室或者低楼层店面最好 -> 出租车容易找到停车位
- 外观普通不显眼但内部有特色 -> 不抢路人眼球但一进就惊喜

### ***3. 开业前三月营销策略***
#### 第一个月：
- 社区推广：发传单到周边住宅小区+贴海报+社交媒体帖子
- 内部试运营收集反馈并优化菜单和服务流程
- 口碑传播：员工主动推荐给新顾客「这家真好吃！」

#### 第二个月：
- 等额送饮活动：消费 x 元得 y 元下次使用券
- 单品闪购：限定时间低价出售招牌单品吸引尝鲜

#### 第三个月：
- 学生优惠日：每周三晚六点后所有饮料打五折
- 忠诚会员卡：首次充值满金额即赠送一杯免费饮品
- 合作推广：与附近书店/画廊举办联合活动增加曝光度

**核心理念**：打造一个让当地人愿意每天光顾的地方。价格亲民但品质不打折。「我们卖的是氛围，是社区归属感。来一次你就知道为什么回头了。」

Q: 请分析社交媒体对青少年心理健康的双重影响：既要讨论积极的一面（社交连接、信息获取），也要讨论消极的一面（焦虑、成瘾、信息茧房）。
============================================================
A: **社交媒体对青少年轻微而深远的影响**

正面影响：

1. 社交连接：帮助孤独学生找到志同道合的朋友和社群。
2. 信息获取：快速接触新闻、教育内容、兴趣爱好资源。
3. 自我表达：平台提供了安全探索身份认同的空间。

负面影响：

1\. 焦虑与比较：社交媒体上展示的是精心挑选的最佳生活片段，导致用户自我贬低；"完美主义-抑郁循环"被放大。
   
2\. 成瘾：即时奖励机制（点赞/评论）刺激大脑多巴胺分泌，难以控制使用时间。

3\. 虚拟现实 vs 实际世界：过度沉浸在虚拟社交中可能导致现实世界的社交技能退化。

4\. 信息茧网效应：算法推送的内容越来越符合用户的偏好，减少了意外发现新观点的机会。

5\. 隐私风险：个人数据收集用于精准广告投放，但可能泄露给第三方。网络欺凌事件频发。

6\. 误导性信息：假新闻泛滥，青少年无法辨别真假。

7\. 模仿行为：易受名人负面行为的影响（自残、药物滥用）。

平衡策略：
- 设定每日使用时间上限
- 关注多元化的关注点而非单一偶像
- 定期离线做真实社交
- 学会批判性思考媒体中的信息
- 保持健康的生活习惯和边界

总的来说，社交媒体是一把双刃剑——它能为年轻人带来前所未有的机会，但也带来了新的挑战。关键在于培养数字素养——理解其利弊并采取措施保护自己免受潜在伤害。

Q: 什么是Agent Skills？它和传统的Prompt Engineering有什么本质区别？在构建复杂AI应用时，Skills架构有哪些优势？
============================================================
A: **Agent Skills 是一种新型 Prompt 架构——从单一长 prompt 转向可组装的独立 Skill 文件**

**核心思想：**
- 将任务拆解成小块（每个 Skill 100-250 行）
- 每个 Skill 放一个文件夹中（skill/summarization），包含：Skill.yaml + 具体实现文件
- Agent 启动时读取所有 Skills 到缓存

**与传统 Prompt 工程的区别：**
| 方式 | 部署频率 | 单一场景 vs 多元场景 |
|------|----------|-----------------------|
| **单个 Long Prompt** | 周/月更新一次 | 所有问题都在同一个文件里 |
| **Skills 架構** | 系统启动时加载所有 | 不同 Skill 可以分别由不同人维护 |

**核心收益：**
1. **更快响应时间**：启动时预热所有常用 Skills → 接入新任务更流畅
2. **隔离变更影响**：修改一个 Skill 的输出格式不会意外破坏其他 Skill
3. **团队协作优化**：不同模块可以并行开发和测试
4. **跨项目复用**：同一技能库可以在多个 AI 应用之间共享

**最佳实践：**
每种常见任务类型单独写一个 Skill：
```
skills/
├── chat_summarization/
│   ├── skill.yaml         # 定义结构化输入+期望输出
│   └── summarize.py       # 实现具体逻辑
└── code_analysis/
    ├── skillyaml
    └─ analyze_code.py
...
```
